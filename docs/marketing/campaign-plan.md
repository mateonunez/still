# Still — preview campaign

## Position

A calm screen for a working Mac. Lead with the moment of stepping away, then show the composition and explain the native implementation. Target Mac users who keep work running and developers interested in configurable, metadata-only widgets.

The call to action is to try the experimental preview and report a focused issue. Every installation announcement links to the download notes. Never describe Still as the macOS security lock, a notarized beta, an offline agent dashboard or a guarantee that every background task progresses.

## Editorial sequence

| Stage | Channel | Material | Success signal |
| --- | --- | --- | --- |
| Introduction | Personal blog + X | Why Still exists, cover art, preview link | Qualified visits and installation feedback |
| Design | X | Porcelain/Glass native view exports, with export provenance | Questions about composition and use cases |
| Engineering | Blog + relevant developer community | Native curtain boundaries and declarative plugin contract | Reproducible issues and useful contributions |
| Feedback | GitHub + X | Changes tied to observed preview reports | Confirmed fixes on reported environments |
| Beta | Personal channels and selected launch hub | Actual interaction recording and signed build | Successful clean installations |

Publish each follow-up after there is new evidence. Avoid repeating the same announcement across communities. Read current posting rules and verify the personal account before each new destination. Do not request votes or send unsolicited DMs.

Show HN is a candidate once trying the app is straightforward: its [official guidelines](https://news.ycombinator.com/showhn.html) require a usable project and discourage barriers, landing-page-only submissions and vote solicitation. The current unsigned installation friction warrants resolving the clean-install path before a broad submission. Other hubs remain candidates pending their rules and account access.
