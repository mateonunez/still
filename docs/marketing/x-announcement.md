# X preview announcement

Prepared for the personal account. Not published.

## Main post

I built Still for the moments when my Mac is working and I want to step away.

A calm screen, configurable widgets, Porcelain and Glass. Native Mac app. Open source, MIT.

Experimental preview is available. Installation notes and known limits:
https://meet-still.app/download

## Follow-up

Still is a visual privacy curtain, not the macOS security lock. This preview is ad-hoc signed and not notarized; gestures and compatibility still need testing.

Why I built it:
https://mateonunez.co/blog/still-a-little-space-to-step-away/
