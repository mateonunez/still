# Brand, copy and MIT phase

2026-10-06. This phase updates marketing and repository materials. Developer ID/account setup remains deferred to final release preparation.

## Product story

The primary brand line is **A little space to step away.** Supporting copy explains screen coverage, owned keep-awake behavior and optional details. The website, repository banner, README and copy guide share that identity. Porcelain/burgundy, Instrument Serif and the ring-and-dot mark remain the brand foundation; Glass is a native theme within it.

The landing now explains the three-step workflow and answers practical questions about authentication, task progress, agent metadata and beta availability. Existing sample labels and native coverage limitations remain visible. An end-user beta is being prepared; no public native download, account collector, payment flow or community installer was added.

## Licensing and repository

Original code and documentation use the MIT license. Root and website package metadata now match the existing MIT native-plugin/CLI metadata. Font licenses and provenance are retained in a separate third-party notice. The public license page and SDK license copies are generated from the root LICENSE; the native builder includes that notice in future app bundles. The existing interactive app was not changed.

README now leads with the product and concise local instructions. CONTRIBUTING separates repository access from public SDK access. The source repository remains private. Commercial pricing and community publishing remain separate decisions.
